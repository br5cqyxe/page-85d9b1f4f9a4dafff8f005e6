操作说明与客户端下载

OxygenProxy 采用通用机场订阅（Clash / Surge 等兼容格式）。请先完成套餐开通，再按系统下载对应客户端并导入订阅链接。官方下载指引仅通过本站页面公布，不通过来历不明的网盘传播安装包。

推荐操作步骤

  1. 在官网确认套餐额度、设备数与年付优惠，完成订阅开通。
  2. 在用户中心复制订阅链接（请妥善保管，勿公开分享）。
  3. 根据设备下载客户端：Windows / macOS 可用 Clash Verge 或 mihomo 系桌面端；Android 可用 Clash Meta for Android；iOS 常用 Shadowrocket、Stash 或 Quantumult X（需自行通过商店获取）；路由器可在 OpenWrt 等环境导入订阅。
  4. 客户端内选择从 URL 导入订阅，粘贴链接并更新节点。
  5. 开启系统代理或 TUN 模式，按规则分流；流媒体与游戏请选择对应地区或 IPLC 节点。
  6. 若变更套餐或续费，在客户端手动更新订阅即可同步流量与节点。

官网下载注意

桌面与安卓客户端请使用开源或官方渠道的稳定版本，并核对发布者。iOS 应用需使用正版商店账号。OxygenProxy 提供订阅与节点，不捆绑来源不明的安装包。遇到证书或系统代理问题，可先关闭再重开 TUN，或切换节点后重试。

常见问题

以下问题覆盖订阅、下载、设备与加速体验，展开即可阅读说明。

OxygenProxy 是 VPN 还是机场？和普通加速器有何不同？

OxygenProxy 以机场订阅方式交付节点，可在 Clash 等客户端中使用，同时承担 VPN 梯子与网络加速职能。区别在于您可按套餐自选节点、自管分流规则，而不是单一封闭线路。官网同时提供套餐、使用说明与客户端导入指引。

如何从官网完成客户端下载并导入机场订阅？

先开通套餐并复制订阅 URL，再按系统安装兼容客户端（见操作说明与客户端下载）。在客户端选择从 URL 更新，等待节点列表刷新后即可连接。请勿从论坛附件或即时通讯群随意下载安装包，以免植入恶意配置。

基础版、旗舰版、团队版分别适合谁？流量不够怎么办？

基础版适合轻度浏览与 3 台设备；旗舰版适合经常看流媒体、打游戏且需要优先支持的用户；团队版面向多成员、高流量或需要定制路由的小团队。流量按月重置，用尽后可等待下月或在官方升级套餐。年付价格已在各卡片标明。

能否解锁流媒体？游戏加速是否一定走 IPLC？

基础版提供基础流媒体解锁；旗舰与团队强调全节点原生解锁，体验更完整。游戏加速方面，旗舰版含 IPLC 专线优化，但仍需在客户端手动选择对应游戏节点，并关闭可能冲突的其他加速器。延迟受本地宽带与路由影响，建议对比多个节点。

支持哪些设备同时在线？路由器算几台？

基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。路由器若作为网关给全家设备上网，通常计为 1 个会话，但下游设备访问海外时仍受节点带宽与套餐流量约束。请避免把账号共享给套餐外的大量用户。

连接失败、订阅更新不了或速度突然变慢如何处理？

依次尝试：检查本地时间与系统代理、更新订阅、更换节点、切换传输方式或不同端口、关闭其他 VPN。若仅个别地区异常，多半是线路波动。旗舰与团队用户可通过优先工单反馈，团队版另有客户经理跟进。

如何确认自己访问的是 OxygenProxy 官网而不是仿冒站点？

请核对浏览器地址栏域名、套餐价格与本页公示一致（基础版 ¥15/月、旗舰版 ¥35/月、团队版 ¥85/月及对应年付）。官方不会以限时破解或免费无限流量引流。收藏本页锚点导航即可反复查阅下载与 FAQ。
